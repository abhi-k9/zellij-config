Plugin System

All plugins are sandboxed WebAssembly — safe and cross-platform
Locations
zellij:nameBuilt-in (ships with zellij) file:~/path.wasmLocal .wasm file
https://…/x.wasmRemote URL — downloaded & cached on first use (pin a release tag, not latest: the cache makes latest non-reproducible). Offline? the pinned files ship in plugins/; load them with file: paths (README: Offline / air-gapped machines) AliasShort name you register in plugins {} to use anywhere
Declaration & usage
// config.kdl — register an alias
plugins {
    // one line — a URL broken inside the quotes would contain a newline
    monocle location="https://github.com/imsnif/monocle/releases/download/v0.100.2/monocle.wasm"

    my-plugin location="file:~/zellij-plugins/x.wasm" {   // ~ = home, every OS
        key "value"   // passed to plugin on init
    }
}
 
// Use anywhere:

// 1. In a layout file
pane { plugin location="monocle"; }

// 2. From the CLI
$ zellij plugin --floating -- monocle

// 3. From a keybind (ours: Ctrl+o, then m)
session {
    bind "m" {
        LaunchOrFocusPlugin "monocle" { floating true; };
        SwitchToMode "Normal"
    }
}

zjstatus aliased

dj95/zjstatus  ·  v0.25.0+ for zellij 0.45  ·  wants pane_frames false (or Ctrl+p z per session)
Purpose
Replacement for compact-bar: mode, session, tabs, swap layout, git branch, clock and more, all configured inside the layout file. Ours is layouts/zjstatus.kdl — Catppuccin Mocha, the same main + shell tabs as the default layout, and its own zjstatus.swap.kdl.
Use it
zellij -s zjs -n zjstatusTry it in a new session (first run: click the bar, then y to grant permissions)
default_layout "zjstatus"Adopt it in config.kdl — and set pane_frames false
Excerpt of layouts/zjstatus.kdl
pane size=1 borderless=true {
    plugin location="zjstatus" {
        color_bg    "#1e1e2e"           // color_NAME → use as $NAME
        color_blue  "#89b4fa"
        color_mauve "#cba6f7"
        // …color_dim, color_red, color_green, … (the full palette)

        format_left   "{mode}#[fg=$mauve,bg=$bg,bold] {session} "
        format_center "{tabs}"
        format_right  "{swap_layout}{command_git_branch}#[fg=$dim,bg=$bg] {datetime} "
        format_space  "#[bg=$bg]"

        mode_normal "#[bg=$blue,fg=$bg,bold] NORMAL "
        mode_locked "#[bg=$red,fg=$bg,bold] LOCKED "
        // …one mode_* per mode: pane, tab, resize, move, scroll,
        //   enter_search, search, rename_tab, rename_pane, session,
        //   prompt, tmux (or mode_default_to_mode)

        tab_normal "#[fg=$dim,bg=$bg] {name} "
        tab_active "#[fg=$blue,bg=$bg,bold,italic] {name} "

        datetime          "{format}"
        datetime_format   "%a %d %b  %H:%M"
        datetime_timezone "America/Denver"   // your IANA zone
    }
}
Widget tokens
{mode}Current mode, styled per mode_normal, mode_locked, …
{session}Session name
{tabs}Tab list, styled per tab_normal / tab_active
{datetime}Clock — datetime "{format}" + a strftime datetime_format + datetime_timezone
{swap_layout}Active swap layout (swap_layout_format)
{command_NAME}Output of a shell command: command_NAME_command, _format, _interval (seconds), _rendermode
Full widget reference: github.com/dj95/zjstatus (wiki)

multitask aliased

leakec/multitask (moved from imsnif)  ·  releases track zellij versions (pin the tag matching your zellij, e.g. v0.45.1)
Purpose
A "mini-CI" in a pane. Launching it opens your $EDITOR on a .multitask file — every save runs the commands in it. Commands in the same block run in parallel; a blank line separates sequential steps, and the next step only starts if every command in the previous one succeeded. Press Enter on a failed pane to re-run it and resume the pipeline.
Launch
Ctrl+o t opt-inCommented out in config.kdl (Unix-only: needs sh and $SHELL) — uncomment to launch it for the focused pane's directory. A second press restarts it.
# From a shell (its README's form; ccwd = where the commands run)
$ zellij action start-or-reload-plugin multitask \
    --configuration "shell=$SHELL,ccwd=$(pwd)"

# Example .multitask file — it's a shell script, so comments use #
cargo fmt --check
cargo clippy          # runs in parallel with the line above

cargo test            # step 2: only if step 1 succeeded
Config keys (optional, passed at launch)
shellShebang for the .multitask file — $SHELL recommended
ccwdWorking directory for the commands (defaults to the session host dir)

Locking is manual by design

no autolock plugin  ·  F12 toggles both ways
The problem locking solves
Zellij's Alt-based shortcuts collide with editor and readline bindings (Alt+h/j/k/l pane focus vs nvim/readline, Alt+f floating panes vs readline word-forward, Alt+n new pane). Locked mode passes every key straight through to the running program.
How we do it
F12Press on entering nvim / helix / lazygit
F12Press again on leaving. Status bar shows LOCKED
keybinds {
    locked {
        unbind "Ctrl g"                    // default: Ctrl+g → unlock
        bind "F12" { SwitchToMode "Normal"; }
    }
    shared_except "locked" {
        unbind "Ctrl g"                    // default: Ctrl+g → lock
        bind "F12" { SwitchToMode "Locked"; }
    }
}
// ⚠ A single top-level  unbind "Ctrl g"  does NOT work — the default binds
//   Ctrl+g in both blocks, so unbind it inside each (verified on 0.45.1).
Why not fresh2dev/zellij-autolock
It auto-locks by reading the focused pane's running command — and forces Normal whenever it doesn't match a trigger. A pane restored by session resurrection doesn't report back as nvim, so it drags you out of Locked mode a fraction of a second after you press F12. A plain toggle always does what you pressed.
If manual gets old
From nvimVimEnter / VimLeave autocmds calling zellij action switch-mode locked / normal
Preset swapCtrl+o c → non-colliding preset (moves defaults off Alt)

Our Layouts

All in layouts/  ·  launch with zellij -s <session> -n <layout>  ·  apply at runtime with Ctrl+o l
default.kdl default
Loaded automatically by plain zellij. A single-line compact-bar and two tabs: main to work in, shell as the safety net that keeps a resurrected nvim's :qa from ending the session.
layout {
    default_tab_template {
        children
        pane size=1 borderless=true {
            plugin location="compact-bar"
        }
    }
    tab name="main" focus=true {
        pane
    }
    tab name="shell" {
        pane
    }
}

Full list: zellij.dev/documentation/theme-list.html
Auto light/dark 0.44.2+
// In config.kdl — switches with your terminal's color scheme
theme_dark  "catppuccin-mocha"
theme_light "catppuccin-latte"
Requires terminal support for CSI 2031 (Wezterm, Ghostty, Kitty) and BOTH lines; until the terminal reports its mode, the static theme applies. explicit_theme_hue "dark" / "light" (0.45.1) pins one side and ignores the terminal's reports — an override, not a fallback.
Custom themes (themes/*.kdl)
themes {
    my-custom {
        text_unselected {
            base 205 214 244; background 30 30 46
            emphasis_0 245 194 231; emphasis_1 137 220 235
            emphasis_2 166 227 161; emphasis_3 249 226 175
        }
        // …same fields for text_selected, ribbon_*, table_*, list_*,
        //   frame_selected (focused border), exit_code_success / _error
    }
}
// ⚠ Each component you include needs base + emphasis_0..3 (background is
//   optional) — `frame_selected { base …; }` alone fails to parse on 0.45.1.
//   Full working file: themes/example-custom.kdl.example — copy it to
//   themes/my-custom.kdl (a .kdl.example file is ignored), then in config.kdl:
//     theme "my-custom"
Each color is 3 numbers (RGB 0–255). Full component reference: zellij.dev/documentation/themes.html — we ship themes/example-custom.kdl.example as a starter.
