Mode System

Modal interface — Ctrl+letter enters a mode; single keys act inside it; Esc/Enter returns to Normal
Ctrl+g→ Locked — keys pass through (manual toggle; classic uses F12) Ctrl+p→ Pane — create, close, focus, resize, float Ctrl+t→ Tab — create, close, rename, reorder
Ctrl+n→ Resize — resize focused pane interactively Ctrl+h→ Move — move focused pane around the grid Ctrl+s→ Scroll — scroll/search the scrollback buffer
Ctrl+o→ Session — detach, switch, configure, layouts Ctrl+b→ Tmux — tmux-compatible bindings layer Ctrl+q unboundQuit zellij — disabled in our config (fat-finger guard); quit via Ctrl+o q instead

Resurrection on
session_serialization true + serialization_interval 60 saves session structure. Reattach with zj attach --create <name> using your actual session name. Verify crash/reboot recovery on your machine; parser checks do not prove recovery. A restored application may have no parent shell; the default layout's separate "shell" tab keeps the session alive while that tab exists.
Keep saved sessions when clearing caches. on_force_close "detach" keeps a running session alive if the terminal window closes; unsaved editor buffers still need their own recovery strategy.

Locked & Tmux

Locked mode — Ctrl+g
Locked mode forwards keys to the running program except the unlock key. Press Ctrl+g before an application that needs Zellij's shortcuts, then again to leave. Status bar shows LOCKED.
Ctrl+gToggle lock; the optional classic local profile uses F12 and frees Ctrl+g for applications
Tmux mode — Ctrl+b
Tmux-compatible layer for muscle memory. Press Ctrl+b then:
% / "Vertical split / horizontal split

n / pNext / previous tab
c / xNew tab / close pane
z / dFullscreen / detach
Space / [Next swap layout / enter Scroll mode

Layouts — KDL Format

<config directory>/layouts/*.kdl  ·  launch: zj -s <session> -n <layout>  ·  apply at runtime: Ctrl+o l
Our shipped layouts
default.kdl default2 tabs: main + shell (nvim :qa safety), 1-line compact-bar at bottom
dev.kdl3 tabs: code (editor 75% + shell 25%), git, logs (split)
zjstatus.kdlOpt-in: the same 2 tabs with a zjstatus bar (wants pane_frames false)
minimal.kdlOne shell pane with the built-in compact bar; no application commands
Each has a *.swap.kdl for Alt+[ / Alt+]. zellij -n welcome uses zellij's built-in welcome screen.
layout {                                  // dev.kdl, condensed
    default_tab_template {
        children                              // your panes go here
        pane size=1 borderless=true {         // 1-line status bar
            plugin location="compact-bar"
        }
    }

    tab name="code" focus=true {
        pane size="75%" { name "editor"; }   // top, large
        pane size="25%" { name "shell"; }    // bottom, small
    }
    tab name="git"   { pane; }
    tab name="logs"  split_direction="vertical" {
        pane size="50%" { name "watch"; }
        pane size="50%" { name "scratch"; }
    }
}
 Pane properties
split_direction"vertical" (side-by-side) or "horizontal" (stacked)
size"70%" or fixed e.g. 1 rows/cols
namePane title shown in frame
command / argsAuto-run on start (e.g. nvim + ".")
cwdWorking directory (absolute or relative)
borderlesstrue — hides frame/title
focustrue — gets focus on open
close_on_exittrue — close pane when command exits
stackedtrue — children become a single-line stack
floating_panes { }Wrap to make panes floating with x y width height
plugin location=e.g. "zellij:tab-bar", an alias ("compact-bar"), or "file:~/x.wasm"
Container structure
layout {} → tab {} → pane {}, with optional default_tab_template for shared chrome (status bar, etc.)
Templates let you reuse:
pane_template name="x" { ... }  then use x as a node.
A special children node marks where child panes are inserted.
Tip: zellij setup --dump-layout default prints the built-in default — useful starting point for hacking.

Keybindings — structure
keybinds { normal { bind "..." { ... } } } — add binds to a specific mode, or use shared_except "locked" { ... } for global ones shared_except "locked" { bind "..." { ... } } — global except listed modes
Top-level unbind "Ctrl q" removes a key the defaults bind in one context (ours does this). A key bound in several contexts (Ctrl+g) must be unbound inside each block — top-level silently fails keybinds clear-defaults=true { ... } — start from zero
